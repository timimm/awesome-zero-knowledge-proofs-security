# AI Skills

This section collects reusable AI-assisted audit workflows for ZK and its smart-contract security work. Each skill is designed as an operational prompt template: it defines when to use the workflow, what project context to collect, and what output structure to produce.

## Skills

- [audit-overview](./audit-overview.md): Generate a structured onboarding overview for a circuit or contract audit target.
- [zk-audit](./zk-audit.md): Run a structured cryptography/ZKP audit workflow and consolidate findings into a final report.
